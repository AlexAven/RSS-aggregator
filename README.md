## RSS-агрегатор
### Описание работы
Приложение для добавления новостей из RSS-ленты в единый список.
Агрегатор обрабатывает валидные ссылки на RSS и добавляет новости в вашу ленту новостей.
Добавленные в ленту новости обновляются в реальном времени. 
### Стек проекта
Проект выполнен на нативном JavaScript с использоваинем библиотеки onChange для подписки на изменения и перерендера только обновившихся данных интерфейса.
### Install
* clone repository;
* ``npm ci`` or  ``make install``
* ``npx dev`` or ``make dev``
